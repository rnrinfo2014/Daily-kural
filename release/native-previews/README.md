# Native Compose previews

These images were drawn from the actual Kotlin/Jetpack Compose UI using Robolectric native graphics at a 360dp viewport. They are development previews, not physical-device screenshots. The owner must verify system bars, gestures, migration and notifications on their Android phone before a store submission.

A separate 320dp / 150% font-size test checks header/control bounds and responsive language selection. Final store screenshots should be captured from the installed native app.
