# Smartiva app branding

The supplied official Smartiva logo was adapted with image generation to preserve its folded S geometry and blue/cyan palette. The master is retained here; the opaque 512 × 512 PNG is the Play Store and Android launcher source. It is a faithful visual adaptation, not a byte-for-byte copy of the supplied JPEG.

The adaptive launcher uses a white background and an inset foreground. Notification icons retain the reading glyph.

Regenerate the feature graphic from the repository root with `node release/render-brand-feature.mjs` (Chromium at `/usr/bin/chromium`).
